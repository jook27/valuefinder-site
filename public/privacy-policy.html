ValueFinder 개인정보처리방침

최종 수정일: 2026년 8월 15일

ValueFinder는 사용자를 식별하거나 추적하지 않습니다. 개인정보를 수집·저장·판매하지 않으며, 서버를 운영하지 않습니다(백엔드가 없습니다). 모든 판단은 사용자의 브라우저 안에서만 이루어집니다.

수집하는 정보

없습니다. 이름, 이메일, 계정, 위치, 결제 정보 등 사용자를 식별할 수 있는 어떤 정보도 수집하지 않습니다.

브라우저가 읽는 정보와 그 이유

  • 현재 탭의 URL과 페이지 내용(DOM): ValueFinder의 콘텐츠 스크립트는 지원되는 6개 금융 사이트 페이지가 열리면 동작할 준비 상태로 자동 로드될 수 있습니다. 다만 페이지 정보를 실제로 읽어 처리하는 것은 사용자가 ValueFinder에서 검색을 실행하거나(원하는 지표를 찾을 때), 그 검색으로 예약된 하이라이트 작업을 이어받아 수행할 때뿐입니다. 어느 금융 사이트의 어느 페이지를 보고 있는지 판단해서, 원하는 재무 지표가 현재 화면에 있는지, 다른 탭에 있는지, 다른 페이지로 이동해야 하는지를 계산하는 데만 사용됩니다. 이 정보는 기기 밖으로 전송되지 않습니다.

기기에 저장하는 정보 (chrome.storage)

  • 슬러그 캐시 (chrome.storage.local): investing.com 종목 슬러그 조회 결과를 로컬에 캐시해 같은 종목을 반복 조회할 때 불필요한 네트워크 요청을 줄입니다. 회사명·티커·슬러그 같은 공개 정보만 담고, 개인정보는 포함하지 않습니다.
  • 대기 중인 하이라이트 작업 (chrome.storage.session): "이동 후 하이라이트" 동작을 위해 어떤 지표를 찾아야 하는지 임시로 저장합니다. 20초 후 자동 만료되며, 브라우저 세션이 끝나면 사라집니다.

두 저장소 모두 사용자의 기기 안에만 있으며, 개발자를 포함해 외부 서버로 전송되지 않습니다.

제3자 서비스로 전송하는 정보

  • investing.com 검색 API (https://www.investing.com/search/service/searchTopBar): 종목 식별자(티커 또는 6자리 코드)를 investing.com 슬러그로 변환할 때, 사용자가 조회하려는 종목명 또는 티커를 검색어로 이 API에 전송합니다. 이는 사용자가 investing.com 검색창에 직접 입력하는 것과 동일한 동작이며, ValueFinder가 이 요청 내용을 별도로 수집·저장·분석하지 않습니다.
  • 위 검색 API 호출을 제외하면, 지원 사이트(Investing.com·네이버페이 증권·Yahoo Finance·Finviz·StockAnalysis·Seeking Alpha)의 페이지 탐색 과정에서 ValueFinder가 외부로 전송하는 정보는 없습니다. 해당 페이지들은 사용자가 브라우저로 직접 열람하는 것이며, ValueFinder는 그 페이지 안에서 스크롤·탭 클릭·하이라이트만 수행합니다.

분석, 광고, 트래킹

사용하지 않습니다. 애널리틱스 SDK, 광고 네트워크, 사용자 행동 추적 스크립트가 포함되어 있지 않습니다.

데이터 판매

해당 사항 없습니다. 수집하는 개인 데이터가 없으므로 판매할 데이터도 없습니다.

상표 고지

ValueFinder는 Investing.com, Yahoo Finance, 네이버페이 증권, Finviz, StockAnalysis, Seeking Alpha와 제휴·제공·후원 관계가 없는 독립적인 도구입니다. 각 사이트명은 해당 소유자의 상표이며, 사용자가 그 사이트를 어디서 찾아야 하는지 안내하는 목적으로만 언급합니다.
